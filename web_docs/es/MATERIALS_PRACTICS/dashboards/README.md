# Dashboards - BiciTierra Market Predicción Comercial

## Materiales

- `01_briefing_powerbi.md`
- `02_kpis_i_visuals.md`
- `03_model_taules.md`

## Finalidad

Dar una guía mínima para construir un dashboard ejecutivo con `Power BI` o una herramienta equivalente.

## Cómo usarlos

- alumnado: diseñar primero las preguntas de negocio y después escoger visuales

## Conexión con la capa analítica nueva

- los visuales del dashboard tienen que salir de preguntas ya exploradas al notebook con `Pandas` y visualización previa
- si el notebook detecta segmentos, outliers o factores clave, el dashboard tiene que decidir qué de esos resultados merecen vista ejecutiva
- no conviene posar al dashboard gráficos que no hayan tenido antes una lectura analítica clara

## Relación con el resto de materiales

- el dashboard no sustituye el `EDA` ni la comparativa de modelos; solo  tendría que mostrar la parte que ayuda a decidir
- si una visual funciona solo porque queda bonita, pero no cambia ninguna lectura de negocio, no tendría que entrar al panel final

## Qué tendría que salir de aquí

- KPIs priorizados
- vista ejecutiva legible en pocos segundos
- conexión clara entre modelo y recomendación
