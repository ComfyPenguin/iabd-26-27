# Píldoras ampliadas

Empieza por el [índex general](docs/index.md): acceso para alumnado y profesorado, once unidades, preparación del entorno y conexión con las semanas.

Consulta el [registre de validació](docs/VALIDACIO.md) para conocer las comprobaciones y sus límites.

Para una presentación local con MkDocs Material, desde esta carpeta y con un entorno virtual activado:

```bash
python -m pip install -r docs/requirements-presentacio.txt
mkdocs serve
```

Las unidades están en `docs/`; los programas se pueden ejecutar sin generar la presentación.
